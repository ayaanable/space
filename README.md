# Starfall

A self-contained Phaser 3 arcade space shooter. Move with WASD/arrows, aim with the mouse, hold the mouse button to fire, and press Space to dash. Destroy comets, collect fragments, and survive escalating waves.

## Run locally

```bash
npm install
npm run dev
```

Build for deployment with `npm run build`. The Vite config uses `/starfall/` automatically in GitHub Actions for GitHub Pages.
